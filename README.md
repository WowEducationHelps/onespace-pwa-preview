# One Space — Responsive PWA Preview

A standalone GitHub Pages demonstration of the One Space visual identity. Includes a 2.5-second SVG/CSS animated splash, pure white full-viewport background, blinking blue caret, and hard cut into a sample landing page. No landscape video stretching or letterboxing.

## Publish

Repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Live URL after deployment: https://woweducationhelps.github.io/onespace-pwa-preview/

## Notes

The logo is an SVG recreation of the selected layered-square concept, not a pixel-perfect extraction of the generated MP4. This is a preview only, with no backend or account functionality. Service worker provides basic offline support. For production, coordinate the splash exit with app readiness. For broader PWA icon compatibility, add PNG icons in 192px and 512px sizes.
